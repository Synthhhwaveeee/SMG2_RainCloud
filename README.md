This works with Super Mario Galaxy 2 (SB4E01). This has not been tested on other regions.

### Setup
You must add the RainCloud class to your `ProductMapObjDataTable.bcsv` like this:
RainCloud, RainCloud (ModelName, ClassName)

There is also particles, effects, and a particle texture included with the module. All three of these can be added to your `Effect.arc` with the use of [Pygapa](https://github.com/AwesomeTMC/pygapa)
